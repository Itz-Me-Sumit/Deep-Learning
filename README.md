# 🧬 Deep Learning — From Scratch + PyTorch & TensorFlow

This repository documents my journey into **Deep Learning**, where I implement neural network concepts **from scratch in Python** first — building real intuition around forward propagation, backpropagation, gradients, and architecture design — before using **PyTorch** and **TensorFlow** for practical implementation.

My focus is always on understanding *why* a neural network learns the way it does, not just building models that work.

Part of my larger [Data Science & ML Journey](https://github.com/Itz-Me-Sumit/Data-Science).

---

# 🧠 What's Inside

### 🔢 Neural Networks — From Scratch
* Perceptron & Multi-Layer Perceptron (MLP) — built from the ground up
* Forward Propagation & Backpropagation (full math derivation)
* Activation Functions (Sigmoid, ReLU, Softmax, etc.) — intuition + implementation
* Loss Functions & Gradient Descent variants
* Weight initialization & optimization basics

### 🔥 PyTorch
* Building and training neural networks with PyTorch
* Tensors, autograd, custom training loops
* Practical model implementation

### 🧮 TensorFlow
* Neural network implementation using TensorFlow/Keras
* Model building, training, evaluation

### 📝 NLP (Natural Language Processing)
* NLP fundamentals — text preprocessing, tokenization
* Core NLP concepts implemented and explored
